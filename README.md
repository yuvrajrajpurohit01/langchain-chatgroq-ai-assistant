# LangChain ChatGroq AI Assistant

A beginner-friendly AI assistant built using **Python, LangChain, and ChatGroq**. This project takes user input and generates relevant responses using a Groq-hosted language model.

## Features

* Interactive terminal-based chatbot
* LLM integration using ChatGroq
* Dynamic prompts using ChatPromptTemplate
* Output formatting using StrOutputParser
* Continuous conversation loop until the user exits

## Tech Stack

* Python
* LangChain
* ChatGroq
* Llama 3.3 70B Versatile

## Installation

```bash
pip install -r requirements.txt
```

Set your `GROQ_API_KEY` as an environment variable before running the project.

## Usage

```bash
python mini_project_1.py
```
